# Blob Image Copy

**Copy the image, not the link.**

[Download the extension ZIP](https://github.com/Elnyxn/blob-image-copy/releases/latest) · [简体中文](README.md)

Works with Blob images embedded in a webpage or opened in a standalone `blob:` tab. Right-click the image, choose **Copy Blob**, and paste. Images go to the clipboard as PNG at their original pixel dimensions, not as original files with metadata.

## Install

1. Download and extract the extension ZIP from Releases.
2. Open `chrome://extensions` in Chrome 119+ and turn on **Developer mode**.
3. Click **Load unpacked** and select the folder containing `manifest.json`.

The menu follows Chrome's display language. Simplified and Traditional Chinese are localized; all other languages fall back to English.

## Privacy

Site access lets the extension read images in standalone Blob tabs. It reads the selected image only when you choose the menu item. It never uploads images or collects data.
